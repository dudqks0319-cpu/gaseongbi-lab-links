# 가성비연구소 링크 랜딩페이지

Threads 프로필 링크용 쿠팡파트너스 랜딩페이지입니다.

## 배포

Cloudflare Pages에서 이 GitHub 저장소를 연결하고 아래 설정을 사용합니다.

- Framework preset: `None`
- Build command: 비워두기
- Build output directory: `/`

## 운영 체크

- 광고 고지는 첫 화면 최상단과 하단에 표시합니다.
- 가격, 할인, 배송 가능 여부는 쿠팡 상품 페이지 기준으로 안내합니다.
- `최저가`, `1위`, `무조건` 같은 과장 표현은 사용하지 않습니다.
- 새 상품 링크는 쿠팡파트너스에서 생성한 링크만 추가합니다.
